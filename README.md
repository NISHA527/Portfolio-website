# Nisha Salehittal — Portfolio

Personal portfolio website for Nisha Salehittal, Product Engineer (Bangalore, India).

- Responsive personal portfolio built with HTML, CSS & JavaScript
- Smooth scrolling between sections
- Light and dark mode (remembered via localStorage)
- Mobile-first, then desktop

## Run it

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```
